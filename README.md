# Shy Notes

Open, accessible, offline-ready study notes built with native Jekyll and Bootstrap 5.

## Features

- **Course Catalog & Sidebar Navigation:** Filter by term, tags, or search; collapsible nested chapters with per-course progress tracking in `localStorage`.
- **Automatic Study Tools:** Every course automatically gets a **Quick Reference** page (for *Return to*, *Bookmark*, and *Review later* section pins) and—whenever glossary data is provided—an interactive **Glossary** with inline hover definitions and page-specific **Key Terms**.
- **Print Preview Studios:** Print a single lesson, a whole section, an entire course (with optional scope-aware glossary appendix and customizable term highlighting), or multi-column glossary study sheets.
- **Display & Accessibility:** Light/Dark/High-Contrast themes, web & system fonts (including OpenDyslexic, Atkinson Hyperlegible, Lexend), custom text sizing/spacing/width/capitalization, Reading Guide, and Screen Magnifier.
- **Installable PWA & Smart Offline Caching:** Installable on phone or desktop; automatically caches only the courses you open and refreshes them silently whenever you're back online.
